# 🍅 Pomodoro Timer

A simple **Pomodoro Timer** built with **Python** and **Tkinter** to improve productivity using focused work sessions and scheduled breaks.

## Features

- 🍅 25-minute Work Timer
- ☕ 5-minute Short Break
- 🌴 15-minute Long Break
- ▶️ Start Work Button
- 🔄 Reset Timer
- 🖥️ Clean GUI
- 🔔 Notification when timer ends

## Technologies Used

- Python 3
- Tkinter

## How to Run

Clone the repository:

```bash
git clone https://github.com/abhinavashish1710/Pomodoro-Timer.git
```

Move into the project folder:

```bash
cd Pomodoro-Timer
```

Run the application:

```bash
python pomodoro_timer.py
```
